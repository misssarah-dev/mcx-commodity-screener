# MCX Commodity Screener

Dark-themed Indian commodity market screener dashboard with live MCX data and TradingView Lightweight Charts™.

## Features

- **Live MCX Data** — Real-time prices for Gold, Silver, Crude Oil, and Natural Gas (sourced from MCX via Angel One)
- **TradingView Lightweight Charts** — Candlestick charts with volume bars for each commodity
- **Bottom Navigation Bar** — Home, Chart, AI Signal, News sections with hover glow effect
- **Top Nav Tabs** — Filter by All, Metals, or Energy with glowing hover transition
- **Screener Table** — LTP, Open, Close, High, Previous Close, % Change, and inline sparklines
- **AI Trading Signals** — Algorithmic BUY/SELL/HOLD signals with RSI, MACD, confidence bars, entry/target/stop levels
- **Market News** — Latest commodity market headlines with category tags
